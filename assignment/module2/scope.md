# 模块二测试范围

## 被测对象

- Arrow 1.4.0（Python 日期时间处理库）
- 被测分支基线：tag `1.4.0`

## 被测功能（本次只测这 4 个）

| 功能 | 作用 | 典型输入 |
| --- | --- | --- |
| `arrow.get()` | 把字符串、时间戳、datetime 等转成 Arrow 对象 | `"2026-09-08"`、`0`、datetime 对象 |
| `.shift()` | 在日期时间上增加或减少年/月/日等 | `days=1`、`months=1` |
| `.format()` | 把 Arrow 对象格式化为指定字符串 | `"YYYY-MM-DD"` |
| `.humanize()` | 输出“3 天前”这类人类友好描述 | 距离当前时间过去/未来的时间点 |

## 不测范围

- 不测 Arrow 的中文等 locale 文案细节；
- 不测 `.humanize()` 之外的其他高级功能（如 `floor`、`ceil`、`span`）；
- 不修改 Arrow 源码；源码仅作为被测对象。

## 为什么选这 4 个

1. 输入输出清晰，容易判断“对不对”；
2. 天然包含等价类、边界值和场景法三种测试设计；
3. 全部是纯本地计算，不需要网络；
4. 功能数量适中，适合单人先完整跑通流程。

## 测试时需要判断的“预期结果”

对每一条测试用例，先根据 Arrow 官方文档和日期常识写出预期，再执行：

- 输入合法时，实际输出必须等于预期；
- 输入非法时，必须抛出明确异常；
- 日期运算遇到月末、闰年、跨年等边界时，结果必须正确。

## 环境

- Python 3.12
- pytest
- 运行命令：在仓库根目录执行 `python -m pytest -v`
